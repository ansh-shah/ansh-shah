# Ansh Shah

I build AI workflows and data tools for finance and operations teams. Models handle the judgment calls, code enforces the rules, and a person reviews what's left.

## Projects

- [prior-auth-archive](https://github.com/ansh-shah/prior-auth-archive): a scorecard of which Medicaid plans require prior authorization for ABA therapy codes, built from the reports plans must post under CMS-0057-F. Every value links to the archived source document. [See the scorecard](https://ansh-shah.github.io/prior-auth-archive/).
- [spendcoder](https://github.com/ansh-shah/spendcoder): turns a corporate card export into GL-coded transactions using your own accounting rules, with an audit trail for every row and a review queue for the uncertain ones.
